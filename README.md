# CryptoStrapon, technical account

This is the technical account of the **CryptoStrapon** project. It is used for repository maintenance and for sending pull requests to community lists. The main projects live in one place: **[github.com/cryptostrapon](https://github.com/cryptostrapon)**.

## Main projects

- [AI scam detector](https://cryptostrapon.com/scam-detector): paste a message, link, wallet address or screenshot and get the red flags. Free, no sign up.
- [Crypto scam quiz](https://github.com/cryptostrapon/crypto-scam-quiz): 50 questions, open source (MIT code, CC BY 4.0 content).
- [Crypto scam glossary](https://github.com/cryptostrapon/crypto-scam-glossary): scam vectors explained, open data.
- [npm-install-audit](https://github.com/cryptostrapon/npm-install-audit): read only script that shows install hooks and risky code before you run npm install.
- [Methodology and investigations](https://github.com/cryptostrapon/cryptostrapon-public): how we check cases.

Site: [cryptostrapon.com](https://cryptostrapon.com)

## About the forks here

Forks in this account exist only to send pull requests to curated lists such as Web3 security resources. They are removed after the requests are resolved.
