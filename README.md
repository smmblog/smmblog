# CryptoStrapon, technical account

This is the technical account of the **CryptoStrapon** project. It is used for repository maintenance and for sending pull requests to community lists. The main projects live in one place: **[github.com/cryptostrapon](https://github.com/cryptostrapon)**.

CryptoStrapon in numbers (from [cryptostrapon.com](https://cryptostrapon.com)): 55 documented scam investigations, $16B+ in documented fraud, 19 scam types explained, a 301 term glossary and a 106 scenario quiz, in English and Spanish.

## Main projects

- [AI scam detector](https://cryptostrapon.com/scam-detector): paste a message, link, wallet address or screenshot and get the red flags. On-chain checks on Ethereum, Polygon, Arbitrum, Base and TRON. Free, no sign up.
- [Crypto scam quiz](https://github.com/cryptostrapon/crypto-scam-quiz): 50 core scenarios in the repo, 106 on the site. Open source (MIT code, CC BY 4.0 content).
- [Crypto scam glossary](https://github.com/cryptostrapon/crypto-scam-glossary): 11 scam vectors in depth in the repo; the full 301 term glossary is on the site.
- [npm-install-audit](https://github.com/cryptostrapon/npm-install-audit): read only script that shows install hooks and risky code before you run npm install.
- [Methodology and investigations](https://github.com/cryptostrapon/cryptostrapon-public): how we check the 55 documented cases.

Site: [cryptostrapon.com](https://cryptostrapon.com)
